
# P6 – Full Semantic Portfolio Page

## Aim
To create a personal portfolio webpage using semantic HTML5 elements.

## Technologies Used
- HTML5
- Visual Studio Code
- Web Browser

## Features
- Header with personal introduction
- Navigation menu with section links
- About Me section
- Education details
- Technical Skills list
- Projects section
- Contact information
- Footer

## HTML Semantic Elements Used
- header
- nav
- main
- section
- article
- footer

## Procedure
1. Created an HTML file named index.html.
2. Added the basic HTML5 document structure.
3. Created different sections using semantic HTML elements.
4. Added navigation links to different sections.
5. Added education, skills, projects and contact details.
6. Opened the webpage in a browser to verify its output.

## Result
Successfully created and tested a personal portfolio webpage using semantic HTML5.
