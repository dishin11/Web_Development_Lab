
# P2: Portfolio Repository with Initial Commit

## Aim
To create a Git repository, configure a .gitignore file and make the initial commit.

## Tools Used
- Git
- GitHub
- Visual Studio Code
- Terminal

## Procedure
1. Initialized Git using git init.
2. Created a .gitignore file.
3. Added project files to the Git staging area.
4. Created the initial commit.

## Result
Successfully created and initialized a Git repository for version control.
