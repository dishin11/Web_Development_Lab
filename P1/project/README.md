
# P1: Project Folder and Terminal Navigation

## Aim
To learn basic terminal commands and practice creating and navigating project directories.

## Commands Practiced

- `pwd` - Displays the current working directory.
- `mkdir` - Creates directories.
- `cd` - Changes the current directory.
- `ls` - Lists files and folders.
- `touch` - Creates new files.

## Procedure

1. Created the Web Development Lab folder.
2. Created the P1 directory.
3. Created a project directory.
4. Created html, css, js and images subdirectories.
5. Created the README.md documentation file.

## Result
Successfully created the project directory structure and practiced basic terminal navigation commands.
