
# P3: Feature-Branch Git Workflow

## Aim
To understand and implement the feature-branch workflow using Git.

## Objectives
- Create a separate feature branch.
- Make changes safely without modifying main.
- Commit changes.
- Push the feature branch to GitHub.
- Merge the feature branch into main.

## Procedure
1. Created a feature branch using git checkout -b.
2. Created a README file.
3. Added changes using git add.
4. Committed changes using git commit.
5. Pushed the feature branch to GitHub.
6. Merged the feature branch into main.

## Commands Used
- git branch
- git checkout -b
- git add
- git commit
- git push
- git merge

## Result
Successfully implemented the Git feature-branch workflow.
