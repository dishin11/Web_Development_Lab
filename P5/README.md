
# P5: Semantic Bio Page

## Aim
To create a personal biography webpage using HTML5 semantic elements.

## Technologies Used
- HTML5

## Semantic Elements Used
- header
- nav
- main
- section
- article
- footer

## Procedure
1. Created an HTML5 document.
2. Added a header containing the page title.
3. Created navigation links.
4. Used sections to organize personal information.
5. Used article elements for biography content.
6. Added a footer.

## Result
Successfully created a personal biography webpage using HTML5 semantic elements.
