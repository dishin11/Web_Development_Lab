
# P4: GitHub README and Version Tags

## Aim
To understand Markdown documentation and create version tags in Git.

## Procedure
1. Created a README.md file.
2. Added project information using Markdown.
3. Documented all laboratory practicals.
4. Created a Git version tag.
5. Pushed the tag to GitHub.

## Commands Used

- `git tag` - Lists version tags.
- `git tag v1.0.0` - Creates a version tag.
- `git push origin v1.0.0` - Pushes the tag to GitHub.

## Result
Successfully created project documentation and learned Git version tagging.
